# popos-kde
Scripts to swap out Cosmic with KDE Plasma, quickly, automated, efficiently.




<img width="256" height="256" alt="image" src="https://github.com/user-attachments/assets/84683fb6-ee9a-4125-bce7-c07860f87c83" />


Cosmic is like depressing GNOME, so here's bash scripts to swap out Cosmic for KDE. 
Keeps all drivers, but does nuke EVERYTHING in COSMIC, only run with caution if you don't want COSMIC. Everything is automated, so it takes away work for you.

Must run `kde.sh` first, `kde2.sh` can ONLY be ran in KDE, open KDE in your greeter, with the gear icon. kde.sh MUST be ran with sudo, kde2.sh does not.
Designed for 26.04 Pop, may also work for 24.04, possibly earlier.

Cosmic-greeter is supported, Ubuntu's packages gives you an option for a login manager when downloading a package with a new display manager. SDDM and Cosmic-Greeter should work.



Breeze for SDDM is recommended, download it with this command.
`sudo apt install sddm-theme-breeze`
